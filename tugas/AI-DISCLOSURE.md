# AI Disclosure – Tugas 4

## 1. Penggunaan AI

Dalam pengerjaan Tugas 4, saya menggunakan AI sebagai bantuan untuk memahami dan mengembangkan layout website menggunakan CSS Flexbox.

## 2. Prompt yang Digunakan

Saya meminta bantuan AI untuk:

* memahami cara menggunakan Flexbox untuk navigasi;
* membuat layout `main` dan `aside` yang dapat menyesuaikan ukuran layar;
* membuat card yang fleksibel;
* membuat badge menggunakan `position: relative` dan `position: absolute`;
* memperbaiki tampilan agar tidak menyebabkan horizontal scroll pada layar kecil;
* memahami cara melakukan pengujian website.

## 3. Saran AI yang Digunakan

Saran AI yang digunakan antara lain:

* menggunakan `display: flex`;
* menggunakan `flex-wrap: wrap`;
* menggunakan `gap` untuk jarak antar elemen;
* menggunakan `flex` atau `flex-basis` agar ukuran elemen dapat menyesuaikan;
* menggunakan `min-width: 0` untuk membantu mencegah overflow;
* menggunakan media query untuk layar sempit;
* menggunakan `position: relative` pada card dan `position: absolute` pada badge.

## 4. Pengujian

Setelah menerapkan kode, saya melakukan pengujian secara mandiri, yaitu:

* menguji tampilan pada layar normal;
* menguji tampilan pada lebar sekitar 320 px;
* menguji zoom 200%;
* menguji zoom 400%;
* menguji keyboard focus;
* memeriksa Flexbox melalui DevTools;
* memeriksa Console dan tidak ditemukan error merah;
* memeriksa Network;
* melakukan validasi HTML menggunakan Nu HTML Checker.

## 5. Perubahan yang Saya Lakukan Sendiri

Saya memahami dan menyesuaikan kode dengan struktur website yang sudah dibuat sebelumnya. Saya juga melakukan pengujian tampilan dan memastikan layout dapat digunakan pada layar lebar maupun layar sempit.

## 6. Pemahaman

Saya menggunakan AI sebagai alat bantu untuk memahami konsep dan menyelesaikan masalah, bukan sebagai pengganti pemahaman saya terhadap kode. Saya dapat menjelaskan fungsi Flexbox, `flex-wrap`, `gap`, `flex-basis`, `min-width`, serta perbedaan `position: relative` dan `position: absolute` pada tugas ini.
